POST /api/search?q=query&limit=50
  Description: Search videos by text query using semantic similarity
  Parameters:
    - q: Search query (required, 1-500 chars)
    - limit: Number of results (1-100, default=50)
  Response: { videos: [...], query: string, total: int }
  Performance: ~300-400ms

POST /api/recommend?video_id=uuid&limit=15  
  Description: Find videos similar to a specific video
  Parameters:
    - video_id: Video UUID (required)
    - limit: Number of recommendations (1-50, default=15)
  Response: { videos: [...], current_video_id: string, total: int }
  Performance: ~200-300ms
